## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/hanafiah-enovade/php-app.git
    ```
2. Navigate to the project directory:
    ```sh
    cd php-app
    ```
3. Install dependencies (if any):
    ```sh
    composer install
    ```
